# 세미나 신청 디자인 리뷰 — Website 가이드 적용 후

검토일: 2026-10-01

## 범위와 판단

실제 동의 화면을 390px 모바일 및 1440px 데스크톱에서 확인했다. 신청폼은 동의 전환 대기 상태라 현재 템플릿과 스타일을 검토했다. 신청폼의 최신 모바일 배치 및 인증 상태는 화면 검증이 필요하다. 실제 SMS 발송이나 신청 제출은 하지 않았다. 이번 리뷰에서 제품 코드는 변경하지 않았다.

Website의 보라색 #541B86, Pretendard, pill 버튼 및 카드 그림자가 적용됐다. 모바일 동의 화면에서 가로 넘침은 없었고 글꼴도 로드됐다. 브랜드 방향은 적절하다. 아래 개선은 브랜드 자체보다 읽기와 인증 흐름의 일관성을 위한 것이다.

## 개선 우선순위

### 1. 동의문 내부 스크롤 안내 — 중간, 화면 확인

390px에서 동의문 높이는 360px이고 전체 내용 높이는 819px이었다. 페이지와 동의문이 각각 스크롤되어, 아래쪽 보유기간과 문의처가 더 있다는 것을 바로 알기 어렵다.

추천: 본문을 페이지 흐름으로 펼치거나, 제한 높이를 유지한다면 영역 아래에 ‘아래로 스크롤하여 전체 내용을 확인해주세요’ 안내와 끝에 도달했는지 알 수 있는 시각적 표시를 제공한다.

증거: [현재 모바일 동의 화면](review-consent-mobile-current.png), [현재 데스크톱 동의 화면](review-consent-desktop-current.png).

### 2. 인증 상태의 브랜드 스타일 — 중간, 코드 확인

신청 기본 버튼은 Website 스타일이지만 인증 영역에는 Bootstrap 기본 alert-info, btn-success, text-warning이 남아 있다. 보라색 신청 흐름에서 청록색 안내, 기본 녹색 버튼, 노란 타이머로 바뀐다.

추천: 인증 안내는 pale-purple 배경과 보라색 텍스트, 인증확인 버튼은 브랜드 보라색, 인증 완료는 Website의 녹색을 사용한다. 오류는 구별 가능한 오류색을 유지한다. 남은 시간은 기본 텍스트로 표시하고 만료 임박 때만 강조한다.

근거: resources/views/upload-form.blade.php 143, 160, 166행. public/css/seminar.css에는 해당 상태에 대한 브랜드 색상 재정의가 없다. 실제 인증 화면의 추가 확인이 필요하다.

### 3. 인증 알림이 입력 흐름을 끊음 — 중간, 코드 확인

인증번호 발송 성공, 자리수 오류, 인증 실패가 브라우저 alert로 표시된다. 발송 성공 안내는 폼 안에도 있어 중복되며, 입력을 시작하려면 팝업을 먼저 닫아야 한다.

추천: 인증번호 영역 안의 상태 메시지로 통합한다. 발송 후 인증번호 입력칸으로 초점을 옮기고, 오류는 해당 입력 바로 아래에 표시한다.

근거: resources/views/upload-form.blade.php 577, 580, 596, 636행.

### 4. 선택 필드의 표시 — 낮음, 코드 확인

시/도, 시/군/구, 학년 / 연령에 일반 텍스트 입력 스타일인 form-control을 사용한다. Bootstrap의 선택용 화살표가 적용되지 않아 선택 가능한 필드라는 단서가 약하다.

추천: form-select를 사용하고 Website의 입력 테두리·높이·둥근 모서리를 함께 적용한다. 좁은 화면에서 선택 문구가 화살표와 겹치지 않는지도 확인한다.

근거: resources/views/upload-form.blade.php 28, 39, 81행.

## 추가 확인할 항목

- 사용자가 요청한 소개 문장 두 개는 현재 inline 구성이다. 모바일에서는 자연스럽게 줄바꿈될 수 있으므로, 한 줄 요구가 데스크톱 한정인지 확인할 필요가 있다. 글자 크기를 줄이거나 가로 넘침을 만들어 강제로 고정하는 방식은 권장하지 않는다.
- 전화번호와 인증번호 전송 버튼은 nowrap으로 설정되어 있다. 현재 Website 글꼴을 적용한 360px·390px 화면에서 번호 전체가 충분히 보이는지 확인해야 한다.
- 제출 버튼은 w-100 및 최소 높이 48px로 구성되어 있다. 현재 신청폼에서 최종 시각 확인이 필요하다.

우선순위는 동의문 읽기 안내 → 인증 알림과 상태 스타일 → 선택 필드 표시 순서다.


## 개선 반영 — 2026-10-01

- 동의문 내부 스크롤을 제거하고 전체 내용을 페이지 흐름으로 표시했다.
- 인증 안내·확인 버튼·완료 상태를 Website의 보라색과 녹색으로 통일했다.
- 인증 팝업을 필드 옆 메시지로 교체하고 발송 성공 시 인증번호 입력칸에 초점을 옮긴다.
- 숫자 6자리 검증, 오류 수정 시 메시지 해제, 시간 만료 시 인증확인 비활성화 및 재전송 후 복구를 확인했다.
- 지역·학년 선택에 화살표를 추가했다. 지역과 기관명 영역을 넓히고 모바일 지역 선택은 세로로 배치해 긴 이름이 잘리지 않도록 했다.
- 소개 문장은 데스크톱에서 한 줄, 모바일에서는 문장 단위로 줄바꿈한다. 전화번호와 전송 버튼은 한 줄이며 신청 버튼은 전체 너비다.
- 360px·390px·768px·1440px 배치를 확인했고 모바일 및 태블릿 가로 넘침은 없었다.
- 화면 관련 PHP 테스트 4개 및 프런트엔드 테스트 10개 통과. PHP 8.5 관련 기존 deprecation 경고가 있다. Blade 컴파일과 diff 공백 검사를 통과했다.
- 실제 문자 발송과 신청 제출은 하지 않았다.
