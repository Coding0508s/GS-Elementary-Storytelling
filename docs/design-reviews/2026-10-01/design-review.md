# 신청폼 디자인 점검

대상: http://127.0.0.1:8000/upload
점검일: 2026-10-01
범위: 동의 화면 및 신청폼. 실제 접수·문자 발송·파일 업로드 제외. 코드 수정 없음.

## 확인한 문제

1. **높음 · 신청 목적 불일치**: 상단은 연사 초청 세미나, 안내는 영상 업로드, 동의 화면은 대회 참가 및 심사·시상. 신청 대상과 완료 결과를 한 용어로 통일해야 함. 브라우저 제목도 GS Elementary Speech Contest로 표시됨.
2. **높음 · 모바일 제출 버튼 줄바꿈**: 390px에서 제출하기가 제출하/기로 갈라짐. 제출 버튼 높이 84px, 취소 48px. 모바일에서는 제출을 전체 너비로, 취소는 아래 텍스트 링크로 배치 권장.
3. **중간 · 과도한 상단 높이**: 390px에서 첫 입력 시작이 화면 약 500px 아래. 로고·행사명·완료 알림·단계·타이틀이 연속하여 입력을 밀어냄. 동의 완료 안내 축약, 상단 간격 감소 권장.
4. **중간 · 숫자만 있는 단계 안내**: 1/2/3은 이후 무엇을 하는지 알려주지 못함. 동의 → 정보 입력 → 접수 완료처럼 의미 있는 단계 이름 표시 권장.
5. **중간 · 접근성 이름 누락**: 시/도 및 시/군/구 선택에 연결된 label이 없고 알림 닫기 버튼의 aria-label이 없음. 각 컨트롤에 개별 레이블 제공 권장.

근거: [모바일 390px](upload-mobile-390.jpg) 및 브라우저 DOM 확인.

6. **높음 · 태블릿 입력 폭 부족**: 768px에서 본문 2열을 유지한 채 지역 입력 너비가 각각 약 82px, 전화번호 입력이 약 111px로 줄어듦. 시/도·시/군/구 안내와 전화번호 예시가 잘림. 태블릿에서는 정보 항목을 1열로 바꾸거나 폼 폭을 늘리고 전화번호와 인증 버튼을 별도 행으로 배치 권장. 근거: [태블릿](upload-tablet-768.jpg).
7. **중간 · 항목 이름과 선택지 불일치**: 학년 아래에 만 3세·만 4세·만 5세·초 1~6학년이 표시됨. 학년/연령으로 변경하고, 개별 학년이 필요한지 신청 목적에 맞춰 결정 권장. 근거: 실제 선택 메뉴 및 [모바일](upload-mobile-360.jpg).
8. **개선 · 선택 질문의 위치**: 강사님께 궁금한 점의 큰 입력란이 필수 학부모 정보보다 먼저 표시됨. 필수 정보와 인증 다음으로 이동하고 선택 항목임을 표시하면 완료 경로가 명확해짐. 근거: [데스크톱](upload-desktop-1440.jpg).

## 접근성 추가 확인
기관명 자동완성 입력에 combobox 역할, aria-expanded, aria-controls, aria-autocomplete가 없어 보조기기가 제안 목록 상태를 파악하기 어려움. 제안 항목도 접근성 트리에서는 일반 텍스트로 노출됨. 키보드 선택 및 스크린리더 전체 동작은 별도 검증 필요. 제목 단계는 h1 → h2 → h5로 건너뜀.

## 양호한 점
- 학생 정보와 학부모 정보의 구분이 명확함.
- 입력 글자 크기 16px, 기본 입력 높이 44px로 모바일 입력의 기본 크기는 양호함.
- 필수 별표와 눈에 보이는 포커스 테두리를 제공함.
- 확인한 360px/390px 화면에서 전체 페이지 가로 넘침은 없음.
- 지역을 고르면 시/군/구가 활성화됨.
- 빈 제출 시 첫 필수 입력으로 이동하며 브라우저 기본 검증이 작동함. 다만 필드 아래에 지속되는 오류 문구도 제공하는 편이 좋음.
- 점검 중 수집된 브라우저 오류·경고 로그 없음.

## 빠른 개선 순서
1. 행사명과 영상 업로드 관련 안내문을 실제 신청 목적에 맞게 통일.
2. 모바일 제출 버튼을 전체 너비로 배치하고 취소는 보조 링크로 변경.
3. 단계 숫자에 동의 / 정보 입력 / 접수 완료 이름 추가.
4. 동의 완료 알림을 한 줄로 줄이고 상단 여백 축소.
5. 태블릿에서 입력 필드를 1열로 전환.

## 종합 평가
디자인 평가 C+: 기본 폼 구성은 명확하지만 신청 목적의 혼재와 모바일·태블릿의 입력/버튼 문제가 접수 경험을 해침. 장식 패턴 평가 B: 보라색은 브랜드와 연결되지만 큰 광택 그림자·외곽 장식·강조 버튼의 그라데이션을 줄이면 입력에 더 집중할 수 있음. 점수는 디자인 리뷰의 정성 평가임.

검증 범위: 1440px 데스크톱, 768px 태블릿, 390px/360px 모바일. 빈 필수 입력 검증, 지역 선택, 기관명 자동완성 노출, 연령 선택. 문자 발송, 인증 성공/실패, 실제 접수, 완료 화면, 성능 지표 및 대비율 전체 검증은 수행하지 않음. 코드 수정 없음.

상태: DONE_WITH_CONCERNS. 발견 사항은 모두 미수정으로 기록함.


## 2026-10-01 수정 결과

사용자 확인: 세미나 신청. 제출 버튼 전체 너비 및 나머지 발견 사항 수정.

- 세미나 신청으로 제목·동의·완료 화면·접수 문자·인증 문자 안내 통일. 영상 초상권 동의 및 미수집 항목을 동의 화면에서 제거.
- 전체 너비의 세미나 신청하기 버튼과 별도 취소 링크. 360px 버튼 268×51px, 줄바꿈 없음.
- 태블릿 정보 항목 1열 전환. 768px 지역 입력 각각 310px, 전화번호 628px.
- 상단 로고/여백 축소, 완료 알림 축약, 장식 배경 및 움직임 정리.
- 동의 / 정보 입력 / 접수 완료 단계 이름과 현재 단계 접근성 상태 적용.
- 필수 입력을 우선 배치하고 강사님께 궁금한 점을 아래 선택 입력으로 이동. 학년 / 연령 이름 정정.
- 지역 선택 및 알림 닫기 레이블, h1/h2/h3 제목 체계, 자동완성 combobox/listbox/option 역할과 선택 안내 적용.
- 자동완성 키보드 선택, Escape 닫기, 늦은 응답 무시 처리. 입력 오류를 필드 아래에 표시하고 수정 시 오류 상태 해제.
- 완료 화면은 실제 접수 정보가 있을 때만 성공 표시. 문자 발송 여부를 확인 없이 완료로 단정하지 않음.

검증: 360/390/768/1440px 실제 화면; 자동완성 ArrowDown·Enter 선택/닫힘; 빈 입력 오류/수정 후 해제; Blade 컴파일; PHP 문법; 자동완성 회귀 테스트 5개 통과; PHP 단위 테스트 실패 없음(총 7개, PHP 8.5 관련 기존 deprecation 경고 있음).

전체 테스트 제한: 기존 Feature/ExampleTest가 config/session.php에 데이터베이스 세션이 고정되어 테스트 DB의 sessions 테이블 누락으로 실패함. 해당 설정은 이번 디자인 수정 범위 밖이므로 변경하지 않음. 실제 문자 발송/신청 제출은 실행하지 않음. 기존 사용자의 미커밋 변경을 보존함. 커밋하지 않음.
